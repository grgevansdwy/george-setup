# Decisions

Append-only log of why this project is the way it is. Never edit an old entry. To change a decision, add a new entry that replaces it, and mark the old one "Superseded by D#" in the index.

Claude reads this before changing anything it records. `/spec` adds entries when you lock a decision.

**Constraint codes** (optional, from the architecture review): C1 What must never go wrong? · C2 How fast must it respond? · C3 What volume and cost? · C4 What does the data look like? · C5 Fixed steps or judgment? · C6 How long does a task live? · C7 Who consumes the output?
